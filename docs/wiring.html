Wiring the F&F LE-03MW meter to an ESP32-C6

This is the wiring that actually works: a nanoESP32-C6, an auto-direction RS485-TTL module and the meter in the distribution board. The animation shows one read cycle, which the firmware repeats every 2 s.

J1/J6 positions come from the carrier board design. When wiring, go by the silkscreen on the devkit (3V3, G, 19, 23).

How to

  1. Switch the breaker off

    The meter's RS-485 terminals are low voltage, but the L1–L3 phases sit right next to them. Keep the breaker off while working in the distribution board.

  2. Power the module

    Module VCC to 3V3, GND to GND. Not 5 V, or the module would drive 5 V logic into the ESP.

  3. Data lines

    GPIO19 → TX and GPIO23 → RX on the module. The module labels its pins from the MCU side, which is why it looks swapped. The module's RX LED blinks on every request from the ESP.

  4. Bus to the meter

    A+ → 21, B− → 20 over a twisted pair. Put the 120 Ω terminator at the meter end only; the module usually already has one (SMD marked "121").

  5. Flash the firmware

    Through the USB-C port marked CH343. Use erase-flash the first time, then only flash so the Home Assistant pairing survives.

    cd firmware && idf.py -p /dev/cu.usbmodem… flash monitor

  6. Check the log

    After boot you should see => using 9600 baud 8E1, FC03, word order ABCD, then a P … kW U …/…/… V line every 2 s.

  7. Pair with Home Assistant

    Turn on Enable test-net DCL usage in the Matter Server add-on. The phone must be on the same network as the Thread border router (ZBT-2). Code: 34970112332.

    34970112332

  8. Permanent power

    Any USB supply, for example a router's USB port. The pairing is stored in NVS, so after a power cut the ESP rejoins Thread and Home Assistant on its own.
